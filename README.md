## Разработка детерминированного конечного автомата (ДКА)

### Формальное описание
M_DFA = (Q, Σ, δ, q0, F)
Q = { q_s | s ∈ {0,1}*, |s| ≤ 4 } ∪ { R }
Σ = {0, 1}
q0 = q_ε
F = Q \ {R}

### Таблица переходов (правила)
- Если |s| < 4: δ(q_s, c) = q_{s·c}
- Если |s| = 4: пусть w = s·c. Если нулей в w ≥ 2, то δ(q_s, c) = q_{s[1..4]·c}, иначе δ(q_s, c) = R.
- δ(R, 0) = δ(R, 1) = R.

## Разработка недетерминированного конечного автомата (НКА)

### Формальное описание
M_NFA = (Q, Σ, δ, q0, F)
Q = {q0, q1, q2}
Σ = {a, b, c}
q0 = q0
F = {q0}

### Таблица переходов
| Состояние | a | b | c |
|-----------|---|---|---|
| → *q0     | {q1} | ∅ | ∅ |
| q1        | ∅ | {q0, q2} | ∅ |
| q2        | ∅ | ∅ | {q0} |
